About the Date Difference Calculator

Count the days between two dates, and the working days too. Choose a Saturday–Sunday weekend or the Friday–Saturday weekend used in much of the Gulf.

How to use it

  1. Pick the start and end dates.
  2. Tick the box if you want to count both the first and last day.
  3. Choose your weekend days and read the total and working days.

The formula

Days between = end date − start date (plus one if both days are counted)

Working days = days between, minus the weekend days

Worked examples

From 11 October 2026 to 19 January 2027 is 100 days, or 14 weeks, 2 days, with 71 working days for a Saturday–Sunday weekend.

With a Friday–Saturday weekend the same period has 72 working days.

Common mistakes to avoid

People forget whether to include the first and last day, which changes the answer by one. Hotel nights do not count the checkout day, while leave days often count both ends. Also remember that working days ignore public holidays here, so subtract those separately if they fall inside your period.

Tips

  • Public holidays are not subtracted. Remove them yourself for an exact work count.
  • Use inclusive counting for things like hotel nights versus leave days. Check which your case needs.
  • For notice periods, check whether your contract counts calendar days or working days.
  • The years, months, days row is useful for service and project durations.

Frequently asked questions

How do I count the days between two dates?

Subtract the earlier date from the later one. Add one day if you want to include both the first and the last day.

Does it handle weekends in the Gulf?

Yes. Choose Friday and Saturday as the weekend and the working day count adjusts.

Are public holidays excluded?

No. Holidays vary by country, so subtract them yourself for an exact figure.

Can the end date be before the start date?

Yes. The calculator shows the same distance between the two dates.

Inclusive and exclusive day counts

A date difference usually counts the elapsed days between two dates, so the start date is not counted as a full elapsed day. Some forms and contracts instead count both the first and last day. Decide which convention the task requires before using the result.

Using the Date Difference Calculator wisely

Working-day estimates also depend on which weekdays are treated as weekends and whether public holidays are excluded. For legal deadlines, visas, payroll or service periods, confirm the applicable counting rule with the responsible authority.
