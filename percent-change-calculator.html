About the Percent Change Calculator

Compare an old value with a new one. See the percent increase or decrease and how much you would need to change to get back.

How to use it

  1. Enter the old value.
  2. Enter the new value.
  3. Read the percent change, the difference and the change needed to return to the old value.

The formula

Percent change = (new − old) ÷ |old| × 100

Worked examples

From 80 to 100 is a 25%. To go back from 100 to 80 you would need a -20% change.

From 100 to 80 is a 20%. To go back from 80 to 100 you would need 25%.

Common mistakes to avoid

Mixing up the base is the usual error. Percent change always divides by the old value. Another mistake is confusing percent with percentage points: moving from 10% to 12% is a 2 point rise but a 20% increase. Finally, equal rises and falls do not cancel out, because they apply to different starting values.

Tips

  • Percent change depends on the starting value, so it is not symmetric.
  • Use it for prices, salaries, grades, website traffic or weight changes.
  • A rise from 2% to 4% is a 100% increase, but only 2 percentage points. Know which one you mean.
  • If the old value is zero the percent change is undefined.

Frequently asked questions

What is the formula for percent change?

Subtract the old value from the new value, divide by the old value and multiply by 100.

Why is a 50% fall followed by a 50% rise not back to the start?

Because each percentage applies to a different base. 100 falls to 50, then 50 rises by 50% to only 75.

What is the difference between percent and percentage points?

Percent change compares values proportionally. Percentage points are the plain difference between two percentages.

Can the result be over 100%?

Yes. If the new value is more than double the old one, the increase is above 100%.

Choose the correct baseline

Percentage change is usually calculated as (new value − original value) ÷ original value × 100. The original value is the baseline. If the original value is zero, percentage change is undefined because division by zero is not possible.

Using the Percent Change Calculator wisely

A rise from 50 to 60 is 20%; a fall from 60 to 50 is about 16.7%. These changes are not equal because they use different starting values. State the baseline whenever reporting percentage change so readers can interpret the number correctly.
